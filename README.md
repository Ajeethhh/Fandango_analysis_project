# Fandango Movie Ratings Analysis

## Project Overview
This project investigates potential biases in movie ratings on ticket-selling platforms, focusing on Fandango. By comparing review scores from multiple sources—including IMDb, Rotten Tomatoes, and Metacritic—we analyze whether ratings are artificially inflated to influence user ticket bookings. The analysis highlights the importance of data transparency and ethical practices in online platforms.

## Key Features
- **Data Cleaning & Preprocessing:** Standardized datasets, handled missing values, and ensured consistency for accurate comparison.
- **Comparative Analysis:** Evaluated discrepancies across platforms to identify potential rating inflation on Fandango.
- **Statistical Insights:** Applied descriptive statistics and visualizations to reveal patterns and anomalies in ratings.
- **Impact Assessment:** Highlighted the potential influence of manipulated ratings on user behavior and booking decisions.

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook
- Git & GitHub for version control

## Key Takeaways
- Discovered evidence of rating discrepancies on Fandango compared to other platforms.
- Demonstrated how data analysis can be used to evaluate transparency and trustworthiness of online services.
- Gained practical experience in **data scraping, preprocessing, analysis, and visualization**.
